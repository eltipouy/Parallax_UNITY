# 🎮 EJERCICIO | PARALLAX EN UNITY | ING. EN VIDEOJUEGOS

¡Bienvenidos al ejercicio de **Parallax en Unity**!

Este proyecto fue desarrollado con fines educativos para estudiantes de **Ingeniería en Videojuegos**, como parte de la materia **Inteligencia Artificial Aplicada en Videojuegos**.

A través de este ejercicio podrás explorar cómo crear un efecto de *parallax* en Unity, utilizando diferentes capas de fondo que se desplazan a distintas velocidades para generar una sensación de profundidad en un entorno 2D.

## 🎯 Objetivo del proyecto

Implementar un efecto de *parallax* en Unity para comprender cómo el movimiento de diferentes capas visuales permite simular profundidad y enriquecer la presentación de escenarios en videojuegos 2D, especialmente en juegos de plataformas.

## 🛠️ Tecnologías utilizadas

- **Motor de desarrollo:** Unity
- **Lenguaje de programación:** C#
- **Tipo de proyecto:** Ejercicio práctico de desarrollo de videojuegos 2D
- **Técnica implementada:** Efecto Parallax
- **Entorno de aplicación:** Videojuegos 2D de plataformas

## 📂 Archivos del proyecto

### Código fuente y recursos gráficos

En este repositorio encontrarás el código fuente y los recursos gráficos utilizados para desarrollar el efecto de *parallax*.

Puedes revisar cómo se organizan las capas del escenario y cómo se implementa su movimiento para generar una sensación de profundidad durante el desplazamiento de la cámara o del jugador.

## 🎓 Uso educativo

Este proyecto está destinado a fines educativos y forma parte del material de apoyo de la materia **Inteligencia Artificial Aplicada en Videojuegos**.

Puedes utilizarlo como referencia para estudiar técnicas de composición visual y movimiento de escenarios, y comprender cómo el efecto de *parallax* puede mejorar la percepción espacial y la presentación de un videojuego 2D.
